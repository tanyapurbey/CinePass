# 🎬 CinePass - Frontend Application

Modern cinema ticket booking interface built with **React 19**, **Vite**, and **Tailwind CSS**.

## ✨ Features
- **Responsive Cinema UI**: Sleek crimson dark/light theme designed for modern cinema discovery.
- **Interactive Seat Picker**: Real-time visual seat map with tiered seating (Premium, Regular, Executive).
- **1-Click Demo Login**: Instant recruiter/tester login button with pre-filled credentials.
- **Admin Management Portal**: Real-time control for movies, auditorium screens, show scheduling, and booking audits.
- **JWT Authentication**: Seamless session persistence and route protection.

## 🚀 Development Setup
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

The frontend will run at `http://localhost:5173`.

## 📦 Production Build
```bash
npm run build
```
